# assets/

Ресурси, потрібні для локалізації, окрім самого тексту.

**Правило: шлях у репо = шлях у грі** (відносно `Starship Troopers_Data\StreamingAssets\`). `build.py` кладе `assets/**` у збірку разом із перекладеними текстами.

Зараз тека порожня — ресурси не потрібні:

- **Шрифти.** Усі шрифти гри, що показують кирилицю (Roboto, Exo 2, Myriad Pro Condensed, Candara, Liberation Sans, Arial), містять повний український набір (Є І Ї Ґ є і ї ґ) — перевірено по вбудованих TTF. Основний TextMeshPro-атлас `Roboto-Medium SDF` динамічний, гліфи генеруються з TTF на льоту. Orbitron (декоративні заголовки) кирилиці не має взагалі, але й для російської він не використовується.
- **Прапор мови** в меню (`Graphics/UI/LanguageFlags/flag_ukrainian`) зашитий у ресурси Unity; підмінити його файлом у `StreamingAssets` не можна. Наслідок — порожнє місце замість прапора, на роботу не впливає.
