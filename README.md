# Starship Troopers: Terran Command — українська локалізація (uk-UA)

Неофіційний фанатський переклад гри **Starship Troopers: Terran Command** (The Artistocrats / Slitherine Ltd.) українською мовою.

> Проєкт не пов'язаний з розробниками та видавцем гри. Усі права на гру належать їхнім власникам.

## Статус

| Складова | Рядків | Чернетка | Вичитано |
|---|---|---|---|
| Інтерфейс, юніти, здібності, технології, досягнення (`Language/`) | 4 061 | 0 % | 0 % |
| Місії: назви, брифінги, цілі, репліки (`Scenarios/*/`) | 3 104 | 0 % | 0 % |

**Чернетка** — переклад є, але не вичитаний (`status=fuzzy`); у збірку потрапляє лише з `build.py --drafts`. **Вичитано** — переклад перевірено людиною (`status` порожній), саме він іде в реліз. Разом 7 165 рядків, ≈61 000 слів (96 службових назв редактора, що починаються з `#`, за приміткою розробників не перекладаються і в таблицю не потрапляють).

Версія гри, під яку робиться переклад: **v6.5.0** (Steam, build 24370371, вересень 2026)

## Встановлення

Гра підтримує додаткові мови «з коробки»: список мов — у текстовому файлі, тексти — у CSV. Локалізація додає українську як **дев'яту мову** поруч з офіційними; оригінальні файли гри не змінюються, крім одного рядка в `languages.txt`.

1. Завантажте архів із [Releases](../../releases).
2. Розпакуйте його в теку гри так, щоб файли лягли в `<тека гри>\Starship Troopers_Data\StreamingAssets\` (типово `C:\Program Files (x86)\Steam\steamapps\common\Starship Troopers - Terran Command\Starship Troopers_Data\StreamingAssets\`). Архів містить:
   - `Language\languages.txt` — список мов з доданим рядком `8 = ukrainian` (замінює оригінал);
   - `Language\ukrainian*.csv` — тексти інтерфейсу (24 файли);
   - `Scenarios\<місія>\text_ukrainian.csv` — тексти місій (84 файли).
3. У грі: **Options → Language → Українська** → перезапустити гру.

Після оновлення гри Steam може повернути оригінальний `languages.txt` — тоді достатньо знову розпакувати архів (файли `ukrainian*.csv` оновлення не чіпають).

**Відомі особливості.** Біля «Українська» в списку мов немає прапора — прапори зашиті в ресурси Unity (`resources.assets`), і додати свій без патчу файлів гри неможливо; на роботу локалізації це не впливає. У Terran Command немає теки модів чи Майстерні для локалізацій (Майстерня приймає лише сценарії), тому файли кладуться прямо в `StreamingAssets` — саме так розробники передбачили додавання мов.

Видалення: прибрати `Language\ukrainian*.csv` і `Scenarios\*\text_ukrainian.csv`, повернути оригінальний `languages.txt` (Steam → Properties → Installed Files → Verify integrity).

З репозиторію: `python tools/build.py` збирає ті самі файли в `build/StreamingAssets/` (`--drafts` включає й невичитані чернетки, інакше беруться лише готові переклади; `--zip` — архів для Releases); у гру збірка не копіюється — встановлення вручну, як вище.

## Гілки

- `main` — лише актуальний стан перекладу. Кожен реліз — тег `<версія-гри>-<номер>`.
- Робота ведеться в короткоживучих гілках (`translate/*`, `fix/*`), які зливаються в `main` і видаляються.

Детальніше — у [CONTRIBUTING.md](CONTRIBUTING.md).

## Глосарій

Усталені переклади імен, термінів і назв — у [translation/glossary.tsv](translation/glossary.tsv). Терміни з глосарію перекладаються тільки так, як там зазначено. Глосарій наповнює конвеєр (`analyze entities` → `glossary suggest`), затверджує людина (очищає `status`). Скорочення (`M.I.`, `HMG`, `D.I.M.`) — окремі рядки глосарія зі своїм перекладом (українська абревіатура або латиницею) і посиланням `short_of` на повний термін.

## Структура репозиторію

```
source/                  — оригінальні файли гри (en) за їхніми шляхами відносно StreamingAssets/; не редагуються вручну
  Language/english*.csv  — інтерфейс, юніти, здібності, технології, досягнення, підказки (24 файли)
  Language/languages.txt — список мов гри
  Scenarios/*/text_english.csv — тексти місій (84 файли)
translation/strings.tsv  — усі рядки для перекладу: file, key, original, translation, status, context, entities, tone
translation/glossary.tsv — глосарій: id, term, variants, translation, note, forms, category, status, short_of (скорочення → id повного терміна)
translation/STYLE.md     — правила стилю перекладу
translation/pipeline.toml — опис проєкту для конвеєра перекладу (формати, плейсхолдери, групування рядків)
assets/                  — ресурси, окрім тексту (зараз не потрібні: шрифти гри вже містять українські літери)
publish/                 — описи для GitHub Releases, посібника Steam і КУЛІ
tools/                   — витягування текстів з гри і збірка локалізації (лише формат гри, без логіки перекладу)
build/                   — результат збірки (не в git)
```

Тексти гри — CSV `ключ,текст` (UTF-8, CRLF): багаторядкові значення в лапках, рядки `//` — коментарі (частина з них — підказки перекладачу на кшталт `//,INFO: {0} is replaced with the DLC name`, вони йдуть у колонку `context`). Кожна мова — свій набір файлів з тими самими ключами: `Language/<мова>.csv`, `<мова>_N.csv`, `Scenarios/<місія>/text_<мова>.csv`. `tools/extract.py` збирає все в один `translation/strings.tsv`; `tools/build.py` генерує з нього файли `ukrainian*` за тією ж розбивкою, що й `english*` (для ключів без перекладу підставляється оригінал). Плейсхолдери `{0}`, `{1}`, теги `<color=#…>`, `<b>`, `<i>`, `\n` і підписи клавіш у квадратних дужках у перекладі зберігаються як є.

Рядки з непорожнім `status` — чернетки: у збірку не потрапляють, доки людина не перегляне їх. Колонки `context` (розділ файлу, примітки з коментарів, назва місії), `entities` (терміни глосарію, що трапляються в рядку) і `tone` (характер рядка: наказ, брифінг, пропаганда, жарт…) — довідкові, для перекладача і конвеєра.

Сам переклад робиться поза цим репозиторієм — конвеєром [localization-pipeline-uk-UA](https://github.com/UKA-Localization/localization-pipeline-uk-UA), який читає `translation/pipeline.toml`, `strings.tsv`, `glossary.tsv`, `STYLE.md` і пише чернетки назад у `strings.tsv`/`glossary.tsv`. Цей репозиторій зберігає лише дані та вміє витягти тексти з гри і зібрати їх назад. Деталі — у [tools/README.md](tools/README.md).

## Публікація
