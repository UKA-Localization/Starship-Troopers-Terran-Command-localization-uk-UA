# Публікація

Матеріали для сторінок локалізації поза GitHub.

| Файл | Куди |
|---|---|
| `github-release.md` | Шаблон нотаток до релізу на GitHub. |
| `steam/guide.uk.bbcode`, `steam/guide.en.bbcode` | Посібник у Steam Community (Guides) з інструкцією встановлення українською та англійською у форматі Steam (BBCode) — вставляти як є. |
| `steam/meta.md` | Назва, розділ, теги посібника; нотатки до оновлень. |
| `kuli.md` | Картка для КУЛІ (Каталог української локалізації, kuli.com.ua): поля форми, опис, короткий опис. |
| `screenshots/` | Скриншоти для посібника, README і КУЛІ: `01–16.jpg`, 3440×1440 (Steam F12). Порядок: мова → меню → режими → планети → кампанії → бойові групи → випробування → місія. Перелік з підписами — у `kuli.md`. |

## GitHub Releases

Основний канал поширення. Тег `<версія-гри>-<номер>` (напр. `6.5.0-1`), архів `STTC-uk-UA-<тег>.zip` з текою
`StreamingAssets/` усередині (`Language/languages.txt`, `Language/ukrainian*.csv`, `Scenarios/*/text_ukrainian.csv`),
нотатки — за `github-release.md` (розділ із `CHANGELOG.md`). Архів робить `python tools/build.py --zip` з `main` без чернеток.

## Steam

Майстерня Steam для Terran Command приймає лише сценарії (карти), а не заміну файлів гри, тож локалізацію туди залити не можна.
Замість цього — **посібник** (Steam Community → гра → Guides → Create a guide) з інструкцією встановлення й посиланням на
Releases; оновлення посібника — вручну після кожного релізу. Текст — у `steam/`.

## КУЛІ

Після першого релізу подати картку на kuli.com.ua за `kuli.md`; при оновленнях — правити версію і стан.
